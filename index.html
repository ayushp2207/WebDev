50 San Francisco stays, side by side.

Every card below is fetched at page load from a 500-listing Inside Airbnb snapshot using fetch() and await — no server, no framework, no build step.

Tick Compare on any card (up to three) and a tray slides up from the bottom to line them up on price, rating, space, and — the fun part — the amenities that only one of them has.

1. Fetch

An async function requests the JSON, checks res.ok, and slices the first 50 records.

2. Render

Each record is mapped to a Bootstrap card template string — photo, host, price, description, amenities.

3. Compare

Selections live in a Set; the tray re-renders from that set and computes which amenities are unique to each pick.
